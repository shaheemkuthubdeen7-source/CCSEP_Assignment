================================================================================
CORPORATE INFORMATION SECURITY POLICY (VERSION 2.4)
Permitted Demonstration Document (Classification: Internal Public)
================================================================================

Effective Date: January 1, 2026
Document Owner: Chief Information Security Officer (CISO)

1. Purpose:
This policy defines standards for password complexity, session timeouts,
and authorized access to internal company resources.

2. Access Control Standards:
- Minimum password length: 12 characters with alphanumeric and special characters.
- Multi-factor authentication required for privileged admin accounts.
- File servers must strictly restrict access to authorized directories only.

3. Document Archive Handling:
Public reports and internal guidances are made available through the corporate
archive service. Unauthorized access to server configuration files is strictly
prohibited and monitored.
